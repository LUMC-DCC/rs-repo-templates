# rs-repo-templates

This repository contains Copier templates for research software. They combine the
RSM metadata contract with a language-neutral repository structure or a Python or R
package scaffold, including tests, documentation, CI, community files, and FAIR
metadata.

## Start here

- **[For template users](users/index.md)** — generate a project and apply template updates.
- **[For service integrators](integrators/index.md)** — validate RSM data and call Copier safely.
- **[For template developers](developers/index.md)** — evolve questions, policies, tasks, and scaffolds.
- **[Context reference](contract/index.md)** — inspect field status and generated targets.
- **[Architecture](architecture.md)** — understand ownership across the related independent projects.
