# For template users

This section is for researchers and research software developers working in a
project that was generated from these templates.

Generated repositories provide the selected repository backbone, metadata,
documentation, CI, and FAIR-oriented files. Language templates also provide
implementation scaffolds where supported. You only need Copier when applying a later template release.

## What to expect

- A language-neutral backbone or a language-appropriate project structure.
- Public metadata such as name, description, license, contributors, and repository links.
- Optional documentation, tests, CI, and interface scaffolds based on the context used.
- Optional community files, pull request templates, and issue forms when
  collaboration support is included.
- Files that are meant to be edited by the project team after generation.
